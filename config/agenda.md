# Agenda
#
# Un événement par ligne, commençant par "- ", champs séparés par des
# barres verticales, dans cet ordre :
#
#     date  →  intitulé  →  lieu  →  type  →  url
#
#   date : AAAA-MM-JJ, ou AAAA-MM-JJ..AAAA-MM-JJ sur plusieurs jours
#   type : salon, conference, podcast, webinaire, autre
#   url  : facultatif
#
# Les événements passés basculent tout seuls dans « Déjà passé ».
# Toute ligne ne commençant pas par "- " est ignorée : ces commentaires
# ne risquent donc rien.
#
# Exemple, à décommenter et adapter :
# - 2026-10-15 | API Days Paris | Paris | salon | https://example.com
